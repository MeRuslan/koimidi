# koimidi — бесплатный тренажёр для MIDI-клавиатуры

**koimidi** — бесплатный open-source тренажёр для фортепиано в браузере: падающие ноты с номерами пальцев, режим «ждёт верного нажатия» и собственный звук для клавиатур, у которых его нет.
Учите пьесы из библиотеки, свои файлы MIDI и MusicXML или любую мелодию из видеоурока в стиле Synthesia.
Без регистрации и без сервера: файлы разбираются на вашем устройстве и никуда не отправляются.

**Открыть:** https://meruslan.github.io/koimidi/ · [English](README.md)

## Зачем

Чтобы выучить мелодию, не читая нот, нужны три вещи сразу: полоски, которые падают на клавиши, номер пальца на каждой полоске и тренажёр, который *ждёт* вас, а не убегает вперёд. Если клавиатура ещё и без своего звука (маленький контроллер вроде Komplete Kontrol M32), браузер должен сам озвучивать нажатия. Ни один из проверенных бесплатных сервисов не делал всего этого вместе, поэтому появился koimidi.

## Что умеет

- **Падающие полоски, цвет = палец.** Номер на нижнем крае полоски, клавиша-цель подсвечена тем же пальцем.
- **Режим «Учить» ждёт вас.** Время замирает на каждой ноте (или аккорде), пока вы её не сыграете. Нажали раньше, чем полоска дошла — засчитывается сразу, полоски плавно догоняют без рывка.
- **«В темпе»** не останавливается и считает опоздания и ошибки. **«Послушать»** играет пьесу за вас.
- **Свой звук.** Небольшой WebAudio-синтезатор озвучивает нажатия, педаль сустейна (CC 64) поддерживается.
- **Настоящий рояль.** Выберите в настройках «Рояль · Salamander»: сэмплы Yamaha C5 (около 10 МБ, скачиваются один раз и дальше работают без интернета), играет [SpessaSynth](https://github.com/spessasus/spessasynth_lib).
- **Свои SoundFont.** Добавьте любой пак `.sf2` или `.sf3` и выберите в нём инструмент; паки хранятся в браузере.
- **Импорт MIDI и MusicXML** (`.mid`, `.midi`, `.musicxml`, `.xml`, сжатый `.mxl`). Разбор в браузере, файлы сохраняются в хранилище браузера (IndexedDB) и остаются в списке «Ваши файлы».
- **Пьесы из видео.** Вставьте ссылку на видеоурок с YouTube в стиле Synthesia (падающие ноты подсвечивают клавиши), возьмите видео из другой вкладки браузера или откройте видеофайл. koimidi проигрывает видео, находит в нём клавиатуру, записывает каждую подсвеченную клавишу, различает руки по цвету и вычисляет темп и такты; пьеса появляется в «Ваших файлах» с аппликатурой, как любой MIDI-файл. Такты можно проверить на маленькой ролл-диаграмме, поменять размер или сдвинуть тактовые черты на долю, послушать — и учить. Видео без подсвеченной клавиатуры можно распознать на слух (это черновик: часть нот может быть неверной, руки делятся по высоте).
- **Автоаппликатура** для обеих рук, если в файле нет пальцев: эргономическая модель затрат в духе Парнкатта и динамическое программирование. Пальцы из MusicXML (`<fingering>`) сохраняются.
- **Своя аппликатура.** Нажмите на полоску и выберите палец (или клавиши `1`–`5`). Выбор сохраняется в браузере для этой пьесы, автоаппликатура перестраивает соседние ноты вокруг него, а ваши пальцы помечены точкой.
- **Экспорт в MusicXML с аппликатурой**, включая ваши правки: распечатать пьесу или открыть её в MuseScore и других нотных редакторах.
- **Отсчёт и метроном.** Режим «В темпе» начинается после такта щелчков; метроном отбивает каждую долю в режимах «В темпе» и «Послушать».
- **Профиль клавиатуры.** Укажите, сколько клавиш у вашего контроллера, или koimidi угадает по имени устройства (Komplete Kontrol M32 → 32 клавиши). Контроллер до 49 клавиш показывается на экране клавиша в клавишу, в той октаве, которая удобна для пьесы; пьесы, которым нужно больше клавиш, помечены в библиотеке и во время игры.
- **Запись своей игры** кнопкой ●: можно прослушать и сохранить в `.mid`.
- **Повтор любого участка по тактам**, плюс кнопки разделов, если в нотах есть реперные буквы.
- **Любая октава** на маленьких клавиатурах с подсказкой, куда жать OCTAVE.
- **Темп 20–100 %**, правая / левая / обе руки, названия нот «до ре ми» или «C D E».
- **Вторую руку играет тренажёр.** Учите правую руку, пока koimidi играет левую по серым полоскам (или наоборот); в режиме «Учить» вторая рука ждёт вместе с вами, и аккорд звучит, когда вы сыграли свою ноту.
- **Прогресс.** Время занятий, точность каждого прохода, полоса ошибок по тактам (нажмите на такт, чтобы повторять его), самые трудные такты и то, как шли проходы по текущему участку. В библиотеке у каждой пьесы видно время и лучший результат.
- **Работает без интернета.** После первого захода всё приложение хранится в браузере; установите его из адресной строки или кнопкой **Установить**, и оно откроется как обычная программа, даже офлайн.
- **Нет MIDI-клавиатуры?** Клавиши компьютера `A`–`L` (белые) и `W E T Y U O` (чёрные), а также клики по экранной клавиатуре.
- **Встроенная библиотека** из 16 свободных пьес, от «Twinkle, Twinkle» до «К Элизе» (часть A), Менуэта соль мажор, Колыбельной Брамса и «Коробейников», набранных для koimidi.
- Интерфейс на русском и английском; настройки и файлы остаются в браузере.

## Требования

Web MIDI работает в браузерах на Chromium: **Chrome, Edge, Brave, Opera** на компьютере и Android.
Safari и Firefox MIDI-клавиатуры не видят; всё остальное там работает с клавишами компьютера.
Для Web MIDI сайт должен открываться по `https://`, с `localhost` или из локального файла.

## Как пользоваться

1. Откройте сайт, подключите клавиатуру, разрешите доступ к MIDI, когда браузер спросит.
2. Выберите пьесу из библиотеки или откройте свой `.mid` / `.musicxml` / `.mxl`.
3. Нажмите подсвеченную клавишу. В режиме «Учить» ничего не движется, пока вы не сыграете верную ноту.
4. Сузьте повтор до нескольких тактов (поля «Такты», кнопки разделов или `[` / `]` во время игры), замедлите темп, повторите, расширьте. В пьесе для двух рук учите одну руку с включённой **«+ вторая рука»**, потом обе.
5. Неудобный палец? Нажмите на его полоску и выберите другой, остальная аппликатура подстроится.
6. Когда станет легко, переключитесь на «В темпе», при желании с метрономом. Запишите себя кнопкой ●, чтобы послушать со стороны.
7. Откройте **Прогресс** (кнопка с графиком), чтобы увидеть, какие такты ещё не получаются, и повторите их.

### Пьеса из видео

1. Нажмите **Из видео** на главном экране и вставьте ссылку на YouTube. Лучше всего подходят простые версии: ищите «<песня> easy piano tutorial».
2. Нажмите **Распознать** и разрешите браузеру показать эту вкладку: так koimidi видит клавиатуру в плеере. Видео играет с начала; полоска под ним показывает клавиши, которые koimidi видит подсвеченными. Быстрая пьеса? Сначала выберите скорость «вдвое медленнее» — так точнее.
3. Когда видео закончится (или вы нажмёте **Готово**), проверьте результат: название, размер, тактовые черты, октаву, если в видео видна только часть клавиатуры. **Послушайте** и нажмите **Открыть в тренажёре**.

Видео, которое не показывается вне YouTube, или ролик с другого сайта: откройте его в соседней вкладке и выберите **Видео из другой вкладки**. Файл с компьютера: **Видеофайл** или перетащите его на страницу.

Горячие клавиши: `Пробел` старт/пауза · `Enter` заново · `[` `]` начало/конец повтора на текущем такте · `Z` `X` октава клавиш компьютера · `1`–`5` палец для выбранной полоски · `Esc` назад в библиотеку.

## Приватность

Нет аккаунта, аналитики и сетевых запросов после загрузки страницы, кроме проверки браузером, не вышла ли новая версия приложения, звука рояля и модели для распознавания на слух (около 1 МБ), которые скачиваются с этого же сайта, когда вы впервые ими пользуетесь, и плеера YouTube, когда вы открываете ссылку на YouTube (видео играет как на YouTube, по его правилам). Во время распознавания koimidi смотрит на показанную вкладку кадр за кадром в памяти; ни кадры, ни звук не сохраняются и никуда не отправляются, а показ вкладки прекращается вместе с распознаванием. Импортированные файлы, паки SoundFont, выбранные вами пальцы, прогресс и настройки хранятся только в вашем браузере (localStorage, IndexedDB и Cache Storage); очистка данных сайта их удаляет. Запись живёт в памяти, пока вы её не сохраните. Никуда ничего не загружается.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: парсеры, экспорт MusicXML, аппликатура, движок практики, прогресс, запись, библиотека, распознавание видео
npm run build      # проверка типов + сборка в dist/
```

Чистый TypeScript + Vite без UI-фреймворка. Структура `src/` описана в [README.md](README.md#development), там же — формат записи пьес для библиотеки. В библиотеку принимаются только произведения из общественного достояния в собственном наборе.

Публикация — workflow GitHub Actions (`.github/workflows/deploy.yml`): тесты, сборка и выкладка `dist/` на GitHub Pages при каждом пуше в `main`.

## Планы

Каждый релиз начинается с обкатки на живом контроллере (Komplete Kontrol M32, Chrome по https); что ломается там, чинится первым.

- **v0.2 — учить свою пьесу** (готово). Правка пальца кликом по полоске; правки хранятся в браузере для каждого файла, автоаппликатура подстраивается вокруг них. Экспорт MusicXML с `<fingering>`. Счёт-вступление и метроном для режима «В темпе». Профиль клавиатуры: диапазон вашего контроллера на экране и предупреждение, если пьеса в него не помещается. Запись своей игры с экспортом в `.mid`.
- **v0.3 — две руки по-настоящему** (готово). Тренировать одну руку, пока вторую играет тренажёр. Статистика прогресса по пьесе и по участку. Офлайн-режим (PWA).
- **v0.4 — звук** (готово). Сэмплированное фортепиано (Salamander Grand Piano в SF3 через SpessaSynth) и свои паки SoundFont (SF2/SF3). Больше свободных пьес в библиотеке.
- **v0.5 — пьесы из видео** (готово). Распознавание видео в стиле Synthesia (ссылка на YouTube, другая вкладка или файл) в пьесу с руками, темпом и тактами; распознавание на слух, если подсвеченной клавиатуры нет.
- **Отложено:** импорт векторного PDF в браузере, MIDI-выход во внешний синтезатор, распознавание сканов (OMR).
