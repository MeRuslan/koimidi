# koimidi — бесплатный тренажёр для MIDI-клавиатуры

**koimidi** — бесплатный open-source тренажёр для фортепиано в браузере: падающие ноты с номерами пальцев, режим «ждёт верного нажатия» и собственный звук для клавиатур, у которых его нет.
Без регистрации и без сервера: файлы разбираются на вашем устройстве и никуда не отправляются.

**Открыть:** https://meruslan.github.io/koimidi/ · [English](README.md)

## Зачем

Чтобы выучить мелодию, не читая нот, нужны три вещи сразу: полоски, которые падают на клавиши, номер пальца на каждой полоске и тренажёр, который *ждёт* вас, а не убегает вперёд. Если клавиатура ещё и без своего звука (маленький контроллер вроде Komplete Kontrol M32), браузер должен сам озвучивать нажатия. Ни один из проверенных бесплатных сервисов не делал всего этого вместе, поэтому появился koimidi.

## Что умеет

- **Падающие полоски, цвет = палец.** Номер на нижнем крае полоски, клавиша-цель подсвечена тем же пальцем.
- **Режим «Учить» ждёт вас.** Время замирает на каждой ноте (или аккорде), пока вы её не сыграете. Нажали раньше, чем полоска дошла — засчитывается сразу, полоски плавно догоняют без рывка.
- **«В темпе»** не останавливается и считает опоздания и ошибки. **«Послушать»** играет пьесу за вас.
- **Свой звук.** Небольшой WebAudio-синтезатор озвучивает нажатия, педаль сустейна (CC 64) поддерживается.
- **Импорт MIDI и MusicXML** (`.mid`, `.midi`, `.musicxml`, `.xml`, сжатый `.mxl`). Разбор в браузере, файлы сохраняются в хранилище браузера (IndexedDB) и остаются в списке «Ваши файлы».
- **Автоаппликатура** для обеих рук, если в файле нет пальцев: эргономическая модель затрат в духе Парнкатта и динамическое программирование. Пальцы из MusicXML (`<fingering>`) сохраняются.
- **Повтор любого участка по тактам**, плюс кнопки разделов, если в нотах есть реперные буквы.
- **Любая октава** на маленьких клавиатурах с подсказкой, куда жать OCTAVE.
- **Темп 20–100 %**, правая / левая / обе руки, названия нот «до ре ми» или «C D E».
- **Нет MIDI-клавиатуры?** Клавиши компьютера `A`–`L` (белые) и `W E T Y U O` (чёрные), а также клики по экранной клавиатуре.
- **Встроенная библиотека** свободных пьес, от «Twinkle, Twinkle» до «К Элизе» (часть A), набранных для koimidi.
- Интерфейс на русском и английском; настройки и файлы остаются в браузере.

## Требования

Web MIDI работает в браузерах на Chromium: **Chrome, Edge, Brave, Opera** на компьютере и Android.
Safari и Firefox MIDI-клавиатуры не видят; всё остальное там работает с клавишами компьютера.
Для Web MIDI сайт должен открываться по `https://`, с `localhost` или из локального файла.

## Как пользоваться

1. Откройте сайт, подключите клавиатуру, разрешите доступ к MIDI, когда браузер спросит.
2. Выберите пьесу из библиотеки или откройте свой `.mid` / `.musicxml` / `.mxl`.
3. Нажмите подсвеченную клавишу. В режиме «Учить» ничего не движется, пока вы не сыграете верную ноту.
4. Сузьте повтор до нескольких тактов (поля «Такты», кнопки разделов или `[` / `]` во время игры), замедлите темп, повторите, расширьте.
5. Когда станет легко — переключитесь на «В темпе».

Горячие клавиши: `Пробел` старт/пауза · `Enter` заново · `[` `]` начало/конец повтора на текущем такте · `Z` `X` октава клавиш компьютера · `Esc` назад в библиотеку.

## Приватность

Нет аккаунта, аналитики и сетевых запросов после загрузки страницы. Импортированные файлы и настройки хранятся только в вашем браузере (localStorage и IndexedDB); очистка данных сайта их удаляет. Никуда ничего не загружается.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: парсеры, аппликатура, движок практики, библиотека
npm run build      # проверка типов + сборка в dist/
```

Чистый TypeScript + Vite без UI-фреймворка. Структура `src/` описана в [README.md](README.md#development), там же — формат записи пьес для библиотеки. В библиотеку принимаются только произведения из общественного достояния в собственном наборе.

Публикация — workflow GitHub Actions (`.github/workflows/deploy.yml`): тесты, сборка и выкладка `dist/` на GitHub Pages при каждом пуше в `main`.

## Планы

Каждый релиз начинается с обкатки на живом контроллере (Komplete Kontrol M32, Chrome по https); что ломается там, чинится первым.

- **v0.2 — учить свою пьесу.** Правка пальца кликом по полоске; правки хранятся в браузере для каждого файла, автоаппликатура подстраивается вокруг них. Экспорт MusicXML с `<fingering>`. Счёт-вступление и метроном для режима «В темпе». Профиль клавиатуры: диапазон вашего контроллера на экране и предупреждение, если пьеса в него не помещается. Запись своей игры с экспортом в `.mid`.
- **v0.3 — две руки по-настоящему.** Тренировать одну руку, пока вторую играет тренажёр. Статистика прогресса по пьесе и по участку. Офлайн-режим (PWA).
- **v0.4 — звук.** Сэмплированное фортепиано (Salamander Grand Piano в SF3 через SpessaSynth) и свои паки SoundFont (SF2/SF3). Больше свободных пьес в библиотеке.
- **Отложено:** импорт векторного PDF в браузере, MIDI-выход во внешний синтезатор, распознавание сканов (OMR).
